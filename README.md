# VTBulkScanner - VirusTotal Bulk URL Scanner

A Python-based bulk URL scanner using the VirusTotal API.

This tool scans multiple URLs from a text file, retrieves VirusTotal detection results, and exports them into CSV, JSON, and HTML reports.

---

## Features

- Bulk URL scanning
- VirusTotal API v3
- CSV report
- JSON report
- HTML report
- Error handling
- Colorized terminal output
- Progress indicator
